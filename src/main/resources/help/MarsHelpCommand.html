Using MARS from a command line.

MARS can be run from a command interpreter to assemble and execute a MIPS program in a batch fashion. If no arguments are provided, MARS starts the graphical IDE. The format for running MARS from a command line is:

java -jar mars.jar [options] program.asm [more files...] [-- arg1 [more args...]]

Items in [ ] are optional. Valid options are:

OptionDescription
-h, --helpdisplay command line help
-a, --assemble-onlyassemble only, do not simulate
--assemble-error-exit-code <code>terminate MARS with integer exit code code if assembly error occurs
--simulate-error-exit-code <code>terminate MARS with integer exit code code if simulation error occurs
--display-format <hex|dec|ascii>display memory or register contents in hexadecimal, decimal, or ASCII. The default is hex.
-b, --briefdo not display register names or memory addresses along with contents
-d, --debugdisplay MARS debugging statements
--delayed-branchingMIPS delayed branching is enabled
--dump <segment-or-range> <format> <file>dump memory contents to file. Current supported segments are .text and .data. Also supports an address range. Current supported dump formats are Binary, HexText, BinaryText, AsciiText. This option may be repeated.
--memory-configuration <config>set memory configuration. Possible values are Default, CompactDataAtZero, and CompactTextAtZero.
--messages-to-stderrdisplay MARS messages to standard error instead of standard output
--no-copyrightcopyright notice will not be displayed. Useful if redirecting or piping program output.
--no-pseudopseudo-instructions or extended instruction formats are not permitted
-p, --projectassemble the specified file and all other assembly files (*.asm; *.s) in its directory
--start-at-mainstart execution at statement having global label main, if defined
--self-modifying-codeprogram can write and execute in either text or data segment
--warnings-are-errorsassembler warnings will be considered errors
--instruction-countdisplay the number of MIPS basic instructions executed
--max-steps <count>maximum count of execution steps to simulate. If 0, negative, or not specified, there is no maximum.
--register <register>display register contents at end of run. The $ prefix is optional. This option may be repeated.
--memory <m>-<n>display memory address range from m to n at end of run. Values may be decimal or hexadecimal and must be word-aligned. This option may be repeated.
--all remaining values are provided to the MIPS program as runtime arguments

If more than one filename is listed, the first is assumed to be the main file unless the global statement label main is defined in one of the files. Exception handlers are not automatically assembled; add them to the file list.

Example: java -jar mars.jar --help
Displays command options and explanations.

Example: java -jar mars.jar --register s0 --register s1 --memory 0x10010000-0x10010010 fibonacci.asm
Assemble and run fibonacci.asm. At the end of the run, display the contents of registers $s0 and $s1, and the contents of memory locations 0x10010000 through 0x10010010.

Example: java -jar mars.jar --assemble-only fibonacci.asm
Assemble fibonacci.asm. Does not attempt to run the program, and the assembled code is not saved.

Example: java -jar mars.jar --max-steps 100000 infinite.asm
Assemble and run infinite.asm for a maximum of 100,000 execution steps.

Example: java -jar mars.jar --project major.asm
Assemble major.asm and all other files in the same directory, link the assembled code, and run starting with the first instruction in major.asm.

Example: java -jar mars.jar major.asm minor.asm sub.asm
Assemble and link major.asm, minor.asm and sub.asm. If successful, execution will begin with the first instruction in major.asm.

Example: java -jar mars.jar --assemble-only --dump .text HexText hexcode.txt fibonacci.asm
Assemble fibonacci.asm without simulating. At end of assembly, dump the text segment to file hexcode.txt in hexadecimal text format with one instruction per line.

Example: java -jar mars.jar --dump 0x10010000-0x10010020 HexText hexdata.txt fibonacci.asm
Assemble and simulate fibonacci.asm. At end of simulation, dump the contents of addresses 0x10010000 to 0x10010020 to file hexdata.txt in hexadecimal text format with one word per line.

Example: java -jar mars.jar --register t0 process.asm -- counter 10
Assemble and run process.asm with two program argument values, "counter" and "10".

The ability to run MARS from the command line is useful if you want to develop scripts to exercise a given MIPS program under multiple scenarios or if you want to run a number of different MIPS programs such as for grading purposes.
